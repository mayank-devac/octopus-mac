# Octopus Beta

Free beta for macOS 14.6 or later. [Download](https://github.com/mayank-devac/octopus-dist/releases) · [Report a bug](https://github.com/mayank-devac/octopus-dist/issues)

Updates and fixes are provided during beta testing only. The final beta will remain available for free, without further support or updates.

Future paid versions are an optional upgrade.

Not notarized by Apple. First launch may require **System Settings → Privacy & Security → Open Anyway**. Accessibility permission is required for window control.
